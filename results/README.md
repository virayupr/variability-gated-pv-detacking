# Results and version provenance

**Critical distinction:** `independent_validation_results.csv` contains an **earlier retrospective NRI ≥ 0.090** evaluation. It is not the revised causal rolling-window NRI = 0.12 external evaluation and has deliberately not been overwritten.

The revised manuscript reports 39 eligible days for each 2018 system, primary five-point-median-filtered closed-cycle equal-day-weighted mean-daily CSI² reductions of −1.7698% (System 1) and −0.4482% (System 2A), with 95% five-day moving-block bootstrap intervals [−5.3583%, +0.3840%] and [−1.2273%, +0.2474%]. Pooled CSI² reductions are +0.5576% and +0.2366%, respectively. Mean simulated incident-irradiance penalties are 0.2215% and 0.1942%.

These revised numbers are manuscript-reported values, **not independently regenerated from the notebook in this repository during this documentation update**. Full reproducibility requires versioned revised code, data-loading steps, frozen configurations, output files and validation checks.

Do not interpret CSI² as fatigue damage or optical attenuation as measured electrical-energy loss.
